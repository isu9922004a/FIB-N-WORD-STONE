⑤ 📐 費波那契 N字分析
N字與月線是兩套不同判斷。新手先記：A＝起漲點、B＝前波高點、C＝回檔低點；A起漲 → B前高 → C回檔 → 再收盤突破B，才是完整費波那契N字確認。
ABC 新手白話：A＝這一組N字的起漲點；B＝A上漲後形成的前波高點；C＝B回檔後形成的有效低點。只有 C 已形成後，再由 C 回升並以完整日K收盤突破 B，才正式啟用 0.618／0.764／1.618。若 C 還沒形成，就算現價先漲過 B，也不能倒推成完整 Fib N字。
